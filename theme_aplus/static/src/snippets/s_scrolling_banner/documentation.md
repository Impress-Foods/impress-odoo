# Infinite Ticker Snippet Documentation

## Overview

The Infinite Ticker is a full-width scrolling text banner that continuously animates text from right to left across the entire width of the viewport. It provides a clean, attention-grabbing way to display announcements, promotions, or important information on your website.

## Features

- **Full-width display**: Spans the entire viewport width regardless of content container width
- **Continuous animation**: Seamlessly loops text for an infinite scrolling effect
- **Customizable text**: Set text content directly from the options panel
- **Customizable speed**: Control animation speed through a simple slider
- **Style customization**: Change background and text colors through the options panel
- **Responsive design**: Adapts properly to all screen sizes

## Technical Specifications

### File Structure

- `s_scrolling_banner.xml`: HTML structure and options definition
- `000.scss`: CSS styling for the ticker
- `000.js`: JavaScript implementation of the ticker functionality
- `options.js`: Options handling for the snippet editor

### HTML Structure

```xml
<section class="s_scrolling_text_banner o_full_width" data-speed="50" data-text="Infinite Ticker">
    <div class="ticker-container">
        <!-- Content is dynamically generated by JavaScript -->
    </div>
</section>
```

### CSS Animation

The ticker uses CSS animations with `transform: translateX()` for smooth, hardware-accelerated scrolling. The animation runs infinitely and is controlled by the speed attribute.

```css
@keyframes tickerMove {
    0% { transform: translateX(0); }
    100% { transform: translateX(-100%); }
}
```

### JavaScript Implementation

The ticker is implemented as an Odoo widget that:

1. Reads configuration from data attributes
2. Dynamically generates ticker items based on screen width
3. Creates duplicate content for seamless looping
4. Applies CSS animations with appropriate timing

## Customization Options

### Text Content

The text content can be customized through the options panel using the "Ticker Text" input field. This sets the `data-text` attribute on the snippet.

### Background Color

The background color can be changed using the standard Odoo color picker in the options panel.

### Text Color

Text color can be customized using the standard Odoo color picker in the options panel.

### Animation Speed

The speed of the scrolling animation can be adjusted using the "Text Speed" slider in the options panel. This sets the `data-speed` attribute on the snippet, which is then used to calculate the animation duration.

- Lower values (10): Slower scrolling
- Higher values (200): Faster scrolling

## Technical Implementation Notes

### Responsive Behavior

The ticker automatically adjusts the number of text items based on the screen width, ensuring that there's always enough content to fill the screen without gaps.

### Performance Considerations

- Uses CSS transforms for hardware acceleration
- Creates only the necessary number of text copies to fill the screen
- Properly cleans up resources when the snippet is destroyed

### Browser Compatibility

The implementation uses standard CSS animations and transforms, which are supported in all modern browsers. The ticker should work reliably in:

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## Integration with Odoo Website Builder

The ticker integrates with Odoo's website builder using the standard snippet system. It follows Odoo 17's best practices for snippet implementation, including:

- Proper use of data attributes for configuration
- Integration with the options system for customization
- Clean separation of concerns between XML, CSS, and JavaScript
- Responsive design principles

## Code Maintenance

If you need to modify the ticker's behavior:

- To change the animation style: Modify the keyframes in the JavaScript file
- To adjust default settings: Change the default values in the XML file
- To add new options: Add them to the XML file and implement handlers in options.js
